# Jarvis ルール索引

`.codex/rules/` は、Jarvis の設計判断を一貫させるための、用途別のプロジェクト規則です。タスクに関係するファイルだけを読み、実装の詳細ではなく責務・境界・判断基準を適用します。

| ファイル | 役割 | 参照タイミング |
| --- | --- | --- |
| `common.md` | 全変更に共通する最小限の規則 | 常に |
| `architecture.md` | モジュール構成と依存方向 | 構成・境界を変更するとき |
| `feature.md` | Featureの設計と連携 | Featureを追加・変更するとき |
| `database.md` | 原本データと検索インデックス | 永続化・検索を変更するとき |
| `llm.md` | LLM境界と安全な出力利用 | AI処理を追加・変更するとき |
| `testing.md` | テスト種別と配置 | テストを追加・変更するとき |
| `infrastructure.md` | ローカル環境と設定 | Compose・環境変数を変更するとき |
| `verification.md` | 変更後の検証と報告 | 実装後 |

## 更新方針

- ルールは、実際に繰り返される設計判断や事故防止に必要な事項だけを追加する。
- 同一の規則を複数ファイルへ複写せず、主題を所有するファイルにだけ記載して他から参照する。
- 既存ファイルの責務に収まる内容は追記し、新しい独立した判断領域が継続的に必要になった場合だけ新規ファイルへ分割する。
- 二つのファイルが常に同時に参照され、独立した判断を含まなくなった場合は統合を検討する。
- 実装・運用の変化で前提が失われた規則は、根拠を確認して更新または削除する。未来の仮説だけで規則を増やさない。
